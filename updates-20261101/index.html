The benchmark now asks

Which improvement matters for phase competition?

Finding 1 · A lower component error is not a phase decision.

Shared errors can cancel. A correction can remove useful cancellation. A lower aggregate RMS can coexist with more wrong orderings.

Finding 2 · The training target must resolve the relevant response.

Raw-force fine-tuning improved validation forces but damaged displacement response in four inspected training entries. The held-out thermal and entropy endpoints also worsened.

Reference layer: Alexandria PBE, fixed-volume harmonic Helmholtz free energy at DFT geometry. The relaxation test uses the model’s geometry. These tests complement the existing SiO₂ Gibbs-transfer and eight-system label work; they do not replace them or form a completed eight-system phase diagram.

F(V,T) = E₀(V) + EZP(V) + Fth(V,T)
δΔF = δΔ(E₀ + EZP) + δΔFth
Notes, methods and evidence

Δ means the same ordered phase difference in model and reference. δ means model minus reference. Fth excludes zero-point energy. No electronic, magnetic or anharmonic contribution is inferred from this harmonic label layer.

01 · Fixed-model audit

Temperature changes which information matters.

Single-phase error can hide useful cancellation.

Interpretation and evidence

The MP_traj thermal cancellation fraction is about 0.70; Omat24 is about 0.47. Cancellation depends on the branch. Static single-phase errors also contain energy-gauge offsets that cancel within composition.

Correction is not yet a general solution.

Smaller volume changes and unchanged coordination associate with stronger cancellation. The DFT entropy-contrast stratification does not show the same clear trend.

Interpretation and evidence

Joint anchor–thermal correction gave no stable, broad gain. Some shrinkage estimators reduced RMS, with limited ordering benefit. Regression slopes support statistical shrinkage rather than a repaired physical scale.

03 · Mechanism analysis · completed

Low-frequency errors survive phase subtraction.

What survives robustness checks?

What does the analysis not establish?

Interpretation and evidence

Changing the near-zero cutoff leaves the result nearly unchanged. After removing the three lowest branches at each q-point, ideal removal below 2 THz still reduces the 1000 K MSE by about 45% [24–61%].

Sorted-frequency matching has no independent mode-identity validation. These are spectral counterfactuals. They do not identify the same physical mode across models, or determine a correct training weight.

A low-frequency-sensitive objective is motivated. A 1/ω² weight is not established. Band attributions include cross terms and cannot be read as independently removable error shares.

Notes, methods and evidence

All 239 formulas contributed to this mechanism analysis. A future objective developed from it is not an untouched confirmation on the same test set.

Low-frequency spectral errors are larger and cancel less strongly between phases. A direct counterfactual asks what would happen if the errors below 2 THz were exactly zero, while the remaining spectral errors stayed fixed.

Geometry is a substantial error channel.

Interpretation and evidence

The relaxation-term RMS is 65–75% of fixed-geometry error RMS at high temperature. This is a magnitude comparison. The terms partly cancel and do not add as error-budget shares.

Available warning features did not solve coverage.

Interpretation and evidence

Static relaxation energy associates with error, but the held-out check did not improve the risk–coverage trade-off. Residual-force magnitude did not provide an effective warning signal either.

Notes, methods and evidence

The successful subset is easier in its error tail. Count failures and non-decisions alongside conditional accuracy. This is a relaxed harmonic workflow, with no thermal expansion or anharmonic phase diagram.

The benchmark contribution

Notes, methods and evidence

Fixed-offset force fine-tuning uses labels FDFT(u) + R₀, with R₀ fixed from the pretrained equilibrium force. At initialization, this focuses the error on displacement response. It is not a pure response loss throughout training because the current equilibrium force can change. The latest author report says it was restarted after a memory failure; no completed result is present in this snapshot.

Fixed-offset force fine-tuning is the second attempt on the same split. Its frozen success rule requires an error ratio ≤ 0.8 and an upper 95% bound below 1. No third phonon-force attempt is allowed on this split if Fixed-offset force fine-tuning fails.

Frozen Fixed-offset force fine-tuning protocol

First, identify the thermodynamic difficulty. Second, measure how models handle it. Method changes test whether the diagnosis is useful. A successful method is still an open result, not a premise of the benchmark.
