Why phase-level outputs need a common reference

A phase-level design makes the pair cycle sum zero by construction:

ΔĜAB + ΔĜBC + ΔĜCA = 0

This algebra does not fix the common energy reference. The protocol must state its reference convention and use only permitted source data to fix it. Do not align a held-out phase with its test labels.

Result II · What

Use the same thermodynamic error questions in every system.

Resolve prediction error into the relative gap, its entropy slope and the margin between competing phases. These diagnostics show which thermodynamic quantities the prediction preserves.

ΔG(T) ≈ ΔG(T₀) − ΔS(T₀)(T − T₀) + R(T;T₀)

At fixed pressure, within smooth phase branches: the first term is the relative gap, the second is the local relative-entropy contribution, and R contains higher-order temperature dependence. An anchor used in fitting must come from permitted training data.

A smaller average error can still select the wrong stable phase.

At each state, the stable phase is the one with the lowest G among the candidate phases. The mean error over all phase pairs is a different quantity.

ΔGij = Gi − Gj     i*(T,P) = arg mini Gi(T,P)
Mean error and phase selection give different rankings. In both SiO₂ seeds, Phase-ID has lower mean ΔG MAE than T3 but selects the wrong stable phase throughout the test tail. Inspect the gap between the two lowest phases to locate the decisive error.

Single-phase shape can hide a phase-gap error

Unchanged temperature shapeĜA = GA + cA
ĜB = GB + cB
Changed phase gapΔĜAB = ΔGAB + cA − cB

Separate phase offsets leave the derivatives unchanged. Their difference can reverse the predicted phase order. These equations are an algebraic example, not measured curves.

Why pair loss does not calibrate absolute G

If the loss uses only phase differences, adding the same temperature-dependent function to all predicted phase curves leaves those differences unchanged.

Ĝi → Ĝi + h(T)   ⇒   ΔĜij is unchanged

The loss then does not identify absolute G. One shared constant fitted on training data does not fix an arbitrary common function of temperature.

A crossing is not always a stable transition

There is no consistent pairwise gain from the declared QH baseline in these controls. This limits the original accuracy claim. It does not prove that QHA is useless when target labels are scarce or absent.

A physical baseline needs a physical domain of validity.

GiQHA(T,P) = minV [Ei(V) + Fvib,iharm(T,V) + PV]

Conventional quasi-harmonic approximation (QHA) uses harmonic vibrations at several volumes. The formula above already includes static energy. It must be added only once.

An imaginary harmonic mode is not proof that vibration is unimportant. Strong anharmonic motion can stabilize a high-temperature phase. It can also make ordinary QHA invalid near the chosen reference structure. Deleting unstable modes does not produce a standard QHA reference.

Physical starting point: from PES to a phase decision

Energy and force labels do not directly provide a finite-temperature free energy.

A machine-learned interatomic potential (MLIP) predicts energy and force for an atomic configuration. Free energy depends on the statistical weights of many configurations. It also depends on the stated Hamiltonian and thermal conventions.

Potential energyEθ(R),   Fθ(R) = −∇REθ
Helmholtz free energyF(T,V) = −kBT ln Z(T,V)
At fixed pressureGi(T,P) = minV [Fi(T,V) + PV]

Entropy comes from the statistical calculation. Differentiating a fitted G curve gives its implied entropy. That derivative does not explain where the model obtained the missing statistical information.

Why add a physical baseline?

Ĝi(T,P) = Bi(T,P) + rθ(zi,T,P)

The baseline B can supply explicit thermodynamic information. The residual model learns the difference from the reference. This idea needs three separate tests.

1 · Is the baseline valid?Does its physics apply to this phase and state?
2 · Is the residual easier to fit?Use the same function and label budget as the direct control.
3 · Does the information transfer?Remove target labels before fitting and model selection.

The local bundle includes readable reports, result tables, scripts, figures and ledger records from the indexed source roots. It does not claim to inspect unknown remote files or include every raw trajectory, model weight or licensed pseudopotential. No new model training, DFT or free-energy integration was run for this page.

The diagrams explain information flow and algebra. They do not add measured observations. Source reuse, diagnostic output and scoped QHA labels remain distinct.
