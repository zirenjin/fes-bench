# FES-Bench public review page

English interactive review edition of the 26 October evidence snapshot, including the 27 October Hf sign and probe-label audits. The SiO2 information-intervention package adds the S1 rank audit and S2 gap/slope/few-shot results, figures, protocol, and scoring scripts. Scientific findings remain provisional and retain their protocol limits. Original operating logs, private machine paths and raw archive documents are excluded; the source registry preserves their identifiers and original hashes. The offline research archive is unchanged.

The published data/review_data.json is a public derivative of the original snapshot. Publication transformations affect source access and path metadata, not scientific scores. The S1/S2 scripts use the frozen artifacts and record input hashes. T2/T3 LOPO training and S4/S5 physical comparisons remain explicitly blocked in the result report.

The 29 October follow-up adds identity-and-direction-aware scoring for the recovered SiO₂ task-checkpoint models and a frozen curvature-query value experiment. The new comparison shows slightly lower gap and slope error in the two-source arm, no phase-decision change, and worse stable-phase accuracy in the three-source arm. The model-derived curvature has not been validated against independent SiO₂ Hessian or phonon labels. The offline source page is updated; this folder has no configured publication remote.
