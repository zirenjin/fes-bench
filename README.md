# FES-Bench public review page

English interactive review edition of the 26 October evidence snapshot, including the 27 October Hf sign audit. All 74 active scientific figure variants and their numerical tables are included. Scientific findings remain provisional and retain their protocol limits. Original operating logs, private machine paths and raw archive documents are excluded; the source registry preserves their identifiers and original hashes. The offline research archive is unchanged.

The published data/review_data.json is a public derivative of the original snapshot. Publication transformations affect source access and path metadata, not scientific scores. Reproduction scripts refer to the complete offline archive; they are not a standalone training/data release.
