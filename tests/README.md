# Test plan by phase

- Phase 0: canonical schema, loader validation, and empty-scaffold audit.
- Phase 1: parsers, unit normalization, common-grid interpolation, crossings,
  and representative-structure audit.
- Phase 2: QH protocol, cache behavior, and phonon-report contract.
- Phase 3: frozen splits and reference/noise evaluation round trips.
- Phase 4: physics-baseline deepmd head behavior and frozen export parity.
- Phase 5: external baselines, synthetic recovery, and checkpoint re-evaluation.

## Deviations from design

None. This is a phase-indexed test plan; tests belonging to later phases are
not created as inert passing placeholders.
