# Legacy delivery records

The six `phase0_delivery.md` through `phase5_delivery.md` files are preserved
locally for audit continuity, but are intentionally ignored and must not be
included in the remote Git history. Their structured, reproducible replacements
are indexed from [`../README.md`](../README.md) and live under
`results/raw_runs/`, `results/tables/`, and `results/audits/`.
